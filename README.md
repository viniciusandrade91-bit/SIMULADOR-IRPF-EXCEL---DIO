# 📊 Simulador e Agregador de IRPF em Excel

Ferramenta desenvolvida como parte dos desafios práticos da **DIO**, com o objetivo de criar um agregador de dados inteligente para auxiliar no controle e organização de informações para a declaração de Imposto de Renda.

## 🚀 Funcionalidades da Ferramenta
* **Painel de Navegação (Dashboard):** Capa interativa com menus de acesso rápido para as abas do sistema.
* **Aba Titular:** Cadastro estruturado de dados pessoais e informações de identificação.
* **Informes Bancários:** Gestão centralizada de saldos e saldos em instituições financeiras com validações.
* **Notas Bancárias & Entradas:** Controle mensal de receitas integradas com listas suspensas dinâmicas.
* **Validação de Dados e Fórmulas:** Uso de funções lógicas avançadas, validações estritas por listas e formatação condicional.

## 🛠️ Tecnologias e Conceitos Aplicados
* **Microsoft Excel / Google Planilhas**
* Validação de Dados (Listas suspensas vinculadas a intervalos)
* Funções Lógicas e de Referência (`SE`, `MÍNIMO`, etc.)
* Hiperlinks internos para navegação dinâmica entre abas
